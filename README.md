## 🚀 Descripción

Portafolio profesional de Isaias Flores, **Full Stack Developer** especializado en tecnologías modernas como **Angular**, **Spring Boot**, **.NET**, **C#**, **SQL Server** y **MySQL**. El diseño presenta una paleta de colores verde profesional (#71d942 y #206401) con efectos modernos y animaciones suaves.

## 🎨 Características del Diseño

### 🌈 Paleta de Colores
- **Verde Claro**: `#71d942` - Elementos principales y acentos
- **Verde Oscuro**: `#206401` - Gradientes y elementos secundarios
- **Blanco/Negro**: Textos y fondos para contraste óptimo

### ✨ Características Principales
- 📸 **Foto de perfil circular** con borde verde y efectos hover
- 🎯 **Sección Tech Stack** con cards interactivas
- 📊 **Barras de progreso** categorizadas por tecnología
- 🏷️ **Tags tecnológicos** con gradientes verdes
- 🔥 **Efectos hover** y animaciones suaves
- 📱 **Diseño completamente responsive**

## 🚀 Instalación y Uso

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/IsaiasFloresJH/PortafolioIsaiasFlores-IF.git
   ```

2. **Agrega tu foto de perfil**:
   - Coloca tu foto como `assets/img/perfil.jpg`
   - Formato recomendado: JPG/PNG, 300x300px mínimo

3. **Abre el proyecto**:
   ```bash
   cd PortafolioIsaiasFlores-IF
   # Abre index.html en tu navegador
   ```

## 📸 Instrucciones para la Foto de Perfil

Para completar el diseño, agrega tu foto profesional:

- **Ubicación**: `assets/img/perfil.jpg`
- **Formato**: JPG o PNG
- **Tamaño**: 300x300 píxeles mínimo
- **Tipo**: Foto de busto profesional
- **Fondo**: Neutro o profesional

La imagen se mostrará como un círculo de 120px con borde verde y efectos hover.
