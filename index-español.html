Sobre mi

¡Hola!

Soy un Desarrollador Full Stack apasionado con experiencia en tecnologías web modernas y soluciones empresariales. Me especializo en crear aplicaciones robustas usando Angular para interfaces dinámicas y Spring Boot con .NET para sistemas backend escalables.

Mi experiencia abarca todo el ciclo de desarrollo de software, desde el diseño de interfaces amigables hasta la implementación de lógica de negocio compleja y la gestión de bases de datos con SQL Server y MySQL. Domino C# y Java, lo que me permite adaptarme a diversos requisitos de proyecto y preferencias de equipo.

Siempre busco aprender algo nuevo y salir de mi zona de confort. Creo en escribir código limpio y mantenible siguiendo las mejores prácticas. Me apasiona resolver problemas complejos y crear soluciones que generen un impacto real en la vida diaria de los usuarios.
